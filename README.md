# 🥗 Meal-Making Application for Patients and Doctors

This is a health application built using Spring Boot and flutter. It allows doctors to assign personalized meal plans to patients based on their health conditions, dietary restrictions, and treatment goals. it a platform to help connect the patients with their doctors for better communication and organization of the patient diet.

## 🌟 Features
- Doctor and patient authentication
- Role-based access control
- Custom meal plan creation and assignment
- Patient meal tracking and feedback
- Doctors meal creation and sending to the patients
- Patients consulting the Meal sent by the Doctor
- Help the patient to keep track of his diet

## 🔧 Technologies
- Java
- Spring Boot
- MySQL
- RESTful APIs
- Flutter
